# Static assets

The code and data layer in this project are newly written. The images below reuse earlier reference recreations so the FoodieNoms visual context stays consistent:

- logo.png: generated smiling food-bag logo recreation, not the original client logo.
- food-sheet.png: generated 2×2 illustrative bakery/lunch/pastry/cafe photograph sheet.
- avatar.png: generated illustrative profile portrait.
- map.png: generated illustrative map, not geographic data.
- icon-192.png and icon-512.png: standard technical icon sizes derived from logo.png.
- icons/: Tabler Icons 3.34.1 official outline SVG assets; MIT license retained in icons/LICENSE.

Replace the recreated raster assets with the client's approved originals when available. No real vendor, student, live GPS or stock source is represented by these images.
